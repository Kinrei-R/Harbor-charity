Project Walkthrough & Technical Flow

A structured overview of the development lifecycle, request flow, and directory layout.

01

Environment & Setup

  • Start Apache & MySQL via XAMPP Control Panel
  • Create MySQL database harbor_db in phpMyAdmin
  • Install Laravel via Composer & configure environment (.env)
  • Scaffold auth using Laravel Breeze Starter Kit
  • Initialize Vite, Tailwind CSS, and Alpine.js assets
02

Database & Models

  • Generate Models + Migrations (-m flag)
  • Define table schemas, columns, types, and foreign key relations
  • Run php artisan migrate to build MySQL tables
  • Configure $fillable properties for mass assignment protection
  • Set up Eloquent relationships (hasMany, belongsTo)
03

Controllers & Business Logic

  • Create HTTP controllers (CampaignController, DonationController)
  • Extract validation rules into dedicated Form Request classes
  • Implement category filtering & dynamic donation logic
  • Structure isolated controllers inside Admin/ namespace
04

Routing & Authorization

  • Register web endpoints inside routes/web.php
  • Assign explicit route names (->name('...')) for maintainability
  • Apply authentication and role middleware for route protection
  • Handle parameter filtering (?category=medical)
05

Views & User Interface

  • Build reusable master layout wrappers (<x-app-layout>)
  • Render database collections using Blade loops (@foreach)
  • Add interactive dropdowns & overlays using Alpine.js
  • Apply Tailwind CSS for dynamic styling and responsive design
06

Testing & Execution

  • Launch development server using php artisan serve
  • Validate registration, campaign creation, and donation flow
  • Implement safety checks with Route::has() helpers
  • Perform cross-device responsive UI testing

HTTP Request Lifecycle in Harbor

Step 1: HTTP Request & Route Resolution

The browser sends a GET request (e.g., /causes?category=medical). The router evaluates the request and matches it to a defined controller action inside routes/web.php.

Route::get('/causes', [CampaignController::class, 'index'])->name('causes.index');

Step 2: Controller Processing

The method CampaignController@index receives request parameters and coordinates database queries with the Model.

Step 3: Eloquent Model & Database Fetch

The Campaign Model executes the SQL query against MySQL and returns dynamic records to the controller.

$campaigns = Campaign::when($request->category, fn($q) => $q->where('category', $request->category))->get();

Step 4: View Compilation & HTML Response

The Controller injects the collection into the Blade view, which compiles component structures, styling, and interactivity into HTML sent back to the browser.

return view('causes.index', compact('campaigns'));
