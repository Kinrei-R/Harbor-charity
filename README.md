# Harbor Charity Platform

Harbor is a modern, open-source charity and fundraising web application built with PHP and the Laravel framework. It is designed to streamline donation management, empower organizations to create and manage charitable campaigns, and provide donors with a seamless way to support causes they care about.

---

## Features

* **Campaign Management:** Full CRUD operations for creating, editing, and managing active fundraising campaigns.
* **Donation Tracking:** Real-time contribution logs and tracking for transparent fund management.
* **User Authentication:** Secure authentication and role management powered by **Laravel Breeze**.
* **Responsive UI:** Clean, modern, and mobile-friendly interface designed with **Tailwind CSS**.
* **MVC Architecture:** Built following clean Model-View-Controller design patterns for maintainability and scalability.

---

## Tech Stack

* **Backend:** PHP, Laravel Framework
* **Frontend:** Blade Templates, Tailwind CSS
* **Authentication:** Laravel Breeze
* **Database:** MySQL / PostgreSQL
